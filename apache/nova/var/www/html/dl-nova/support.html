Security & Integrity

Cryptographic Checksum Verification

Verify that downloaded packages have not been altered or corrupted in transit by validating their cryptographic SHA-256 fingerprint.

Linux / Rocky Linux CLI

Use standard core utilities available in all Enterprise Linux systems:

$ sha256sum <filename>

Compare the 64-character output directly with the SHA-256 signature displayed on the resource card.

macOS Terminal

Use the built-in Perl SHA utility:

$ shasum -a 256 <filename>

Outputs the exact SHA-256 digest alongside the target filename.

Windows PowerShell

Run the native cryptographic cmdlet:

PS> Get-FileHash <file> -Algorithm SHA256

Inspect the Hash property returned in the formatted output table.
